> **Quick answer:** Dial **`*323#`** from your Airtel Nigeria line to check your current data balance. Airtel says the same code also shows the expiry date of your active data subscription.

This is the simplest method because it works without opening an app or using mobile data.

## Check Airtel data balance with USSD

On the Airtel line you want to check, dial:

**`*323#`**

Follow the response shown on your screen if Airtel presents a menu.

Airtel's current Nigeria FAQ lists `*323#` as its data-balance code, and its data-plan page gives the same instruction.

## Check when your Airtel data expires

Airtel says **`*323#`** also displays the validity or expiry date alongside the data balance.

This matters if you have a large balance but only a short time left to use it.

Do not assume that the size of the remaining bundle tells you how long it remains valid.

## Check in the My Airtel app

Airtel also provides account and data information through its self-care app.

If you already have the official My Airtel app installed, open it and view your account or data section to check the remaining allowance.

USSD is usually faster for a single balance check. The app is more useful when you want to manage several account settings in one place.

## Useful Airtel short codes

Airtel's current user guide lists harmonised codes for common services. Some useful ones are:

| Service | Current code |
| --- | --- |
| Data balance | `*323#` |
| Data plans | `*312#` |
| Airtime balance | `*310#` |
| Recharge | `*311#` |
| Me2U / sharing | `*321#` |
| Self-service | `*121#` |

These are different services, so using the wrong code can open a menu that has nothing to do with your data balance.

## Why an old Airtel balance code may fail

Older Nigerian telecom articles can still appear in Google after the networks have changed their USSD codes.

If you find an old guide telling you to use a retired balance code, use Airtel's current **`*323#`** instruction instead.

## Data balance is available but browsing is not working

Your balance and your internet connection are two separate things.

If `*323#` shows that data is available but websites or apps still cannot connect:

1. Confirm mobile data is turned on.
2. On a dual-SIM phone, make sure Airtel is selected as the mobile-data SIM.
3. Toggle airplane mode on briefly, then off.
4. Restart the phone.
5. Check whether the problem affects every app or only one.
6. Test another location if signal is unusually weak.
7. Avoid changing APN settings unless simpler checks fail.

If possible, test the Airtel SIM in another phone. That helps separate a network/SIM issue from a setting on your device.

## Why your Airtel data may be finishing quickly

Airtel's own FAQ notes that heavy streaming, social-media video and automatic application updates can consume data quickly.

If your balance drops much faster than expected, check your phone's mobile-data usage screen before concluding that the balance is wrong.

Look for:

- video streaming;
- automatic app updates;
- cloud photo/video backups;
- social apps playing videos automatically;
- hotspot/tethering usage; and
- apps using mobile data in the background.
