> **Quick answer:** To transfer data from your existing MTN Nigeria balance, dial **`*312*PhoneNumber*DataAmount#`**. You can also dial **`*321*2#`** and follow the Data Share menu, or text **`Transfer PhoneNumber DataAmount`** to **`312`**.

MTN uses the word **gifting** for several related actions, so it helps to know what you actually want to do before choosing a code.

You can:

- transfer part of your existing data balance;
- buy a fresh data bundle for another MTN number; or
- request data from another MTN customer.

Those are different actions.

## Transfer data from your existing MTN balance

For a direct transfer, dial:

**`*312*PhoneNumber*DataAmount#`**

Replace `PhoneNumber` with the recipient's MTN number and `DataAmount` with the supported amount.

For example, the structure for transferring 100MB is:

`*312*recipient-number*100#`

MTN says you should enter the amount as a number without adding `MB` or `GB` to it.

Double-check the phone number before confirming. A successful transfer to the wrong number is much harder to undo than correcting the number before you send it.

## Share MTN data through the menu

If you do not want to remember the direct format, dial:

**`*321*2#`**

Then use the Data Share/transfer option and follow the prompts for the recipient and amount.

This takes a few more steps but reduces the chance of typing the direct code incorrectly.

## Share MTN data by SMS

MTN also lists this SMS format:

**`Transfer PhoneNumber DataAmount`**

Send it to:

**`312`**

Again, the data amount should be entered as the number MTN expects rather than adding MB or GB text to it.

## How much MTN data can you transfer?

MTN's current help information lists these transfer sizes:

- 100MB
- 200MB
- 500MB
- 1GB
- 2GB
- 3GB
- 5GB

MTN also says you must retain at least **100MB** in your own data balance after the transfer for it to succeed.

At the time this guide was verified, MTN stated a cumulative transfer limit of **5GB per day** and up to **10 transfer transactions per month**.

Because network rules can change, check the official MTN page if you are making a large or repeated transfer and the menu rejects it.

## Buy a new data bundle for someone else

This is different from transferring data you already own.

MTN lets you buy a specific bundle for another MTN user with this structure:

**`*312*BundleActivationCode*BeneficiaryPhoneNumber#`**

You pay for the new bundle rather than taking the amount from your existing data balance.

If your goal is simply to send someone some of the data you already have, use the transfer method instead.

## Request data from another MTN user

MTN's current Data Gifting information provides a request option inside its gifting service.

The exact short menu can change, so for a request rather than a transfer, the safest route is to open the current Data Gifting menu through **`*312*8#`** or **`*321*2#`** and choose the request option shown on your line.

This avoids relying on an old nested code copied from an outdated article.

## Can you share MTN data in the myMTN app?

Yes. MTN lists the myMTN app as another Data Gifting channel.

Inside the app, look for the **Share** area and then **Data Share**. The app may ask you to authenticate before completing the action.

The app is useful when you want a visual confirmation of the recipient and amount before sending.

## Why an old MTN sharing code may fail

Search results still contain guides using older MTN short codes. That is a problem with telecom tutorials: the article can stay indexed even after the network changes the service path.

If a code from an old page fails, do not keep retrying it. Use MTN's current `312`/`321` instructions or the myMTN app.

## If MTN data transfer is not working

Check these before assuming the service is down:

1. Confirm the recipient is an MTN Nigeria line.
2. Check that your main transferable balance is large enough.
3. Leave at least 100MB in your own balance after the transfer.
4. Try one of the supported transfer amounts.
5. Check the recipient number carefully.
6. Retry through the `*321*2#` menu if the direct format fails.
7. Check the myMTN app or official MTN help page for a rule change.
