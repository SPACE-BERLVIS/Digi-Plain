> **Quick answer:** Nigeria now uses harmonised short codes across the major mobile networks. Dial **`*310#`** to check airtime balance, **`*311#`** to recharge, **`*312#`** to buy/manage data, **`*323#`** to check data balance, **`*303#`** to borrow airtime or data, **`*321#`** for sharing services, **`*305#`** to manage or stop value-added services, and **`*996#`** for NIN/SIM-related services. **300** is the common customer-care number.

If you still remember codes such as MTN `*556#`, Airtel `*123#` or Glo `*124#`, be careful when following old tutorials. Nigeria's telecom operators moved to a common set of short codes so that the main actions use the same code regardless of whether your SIM is MTN, Airtel, Glo or 9mobile.

## Current unified USSD codes in Nigeria

| What you want to do | Current code |
| --- | --- |
| Call customer care | `300` |
| Borrow airtime or data | `*303#` |
| Stop/manage services | `*305#` |
| Check airtime balance | `*310#` |
| Recharge airtime | `*311#` |
| Buy/manage data plans | `*312#` |

| Check data balance | `*323#` |

| Do Not Disturb complaints | `2442` |
| Mobile number portability | `3232` |

The important change is that these core codes are harmonised. You no longer need a completely different balance or data-plan code for each of the four major networks.

## Code to check airtime balance: *310#

Dial **`*310#`** to check your main airtime/account balance.

This is the current harmonised balance code. If an older article tells you to use a network-specific code, start with `*310#` instead.

For Airtel users, we have a separate explanation in [Airtel airtime balance code](/internet/airtel-airtime-balance-code/).

## Code to recharge airtime: *311#

For voucher recharge, the common recharge service is **`*311#`**. The exact prompt or PIN format displayed can depend on the operator, so follow the menu or instructions provided by your network rather than copying an old recharge string from the web.

## Code to buy data: *312#

Dial **`*312#`** to access data plans on MTN, Airtel, Glo or 9mobile.

The available bundles, prices and menu options are still controlled by each network. The code is common; the plans are not necessarily the same.

See our fuller [data plan code guide for Nigeria](/internet/data-plan-code-nigeria/) if you want to understand how `*312#` works across the networks.

## Code to check data balance: *323#

Dial **`*323#`** to check your data balance.

This is one of the most useful changes because old search results still contain network-specific data-balance codes. Current operator information increasingly points customers to the harmonised `*323#` route.

We have network-specific troubleshooting guides for [Airtel data balance](/internet/airtel-data-balance-code/) and [Glo data balance](/internet/glo-data-balance-code/).

## Code to borrow airtime or data: *303#

Dial **`*303#`** to access borrowing services supported by your network.

Whether you qualify, how much you can borrow and the applicable charges depend on the operator and your account. The common shortcode does not mean every network offers identical borrowing terms.

## Code to share airtime or data: *321#

The harmonised sharing-services code is **`*321#`**.

The menu and the kinds of balances you can transfer vary by network. For example, if you use Airtel, see our current guide to [transferring Airtel airtime](/internet/how-to-transfer-airtime-airtel/).

## Code to stop unwanted services: *305#

Dial **`*305#`** for the common stop/manage-services function. This is useful when you need to review or stop eligible value-added services attached to your line.

For unsolicited messaging complaints, **2442** remains the Do Not Disturb shortcode.

## NIN and SIM code: *996#

The common shortcode for NIN/SIM registration and linkage-related services is **`*996#`**.

Because NIN processes involve identity information, follow the prompts from your network and use official operator or NIMC channels. Do not send your NIN to an unofficial person who claims they can link your SIM remotely.

## Customer care number: 300

For the main mobile networks, **300** is the harmonised call-centre number.

Your network may still publish other contact channels such as an app, web chat or social support account, but 300 is the common short number for customer-care access from a mobile line.

## Why did Nigeria change the old USSD codes?

The Nigerian Communications Commission introduced harmonised short codes to reduce the confusion created by every mobile network using a different code for the same basic task.

That means a person with multiple SIMs can remember `*310#` for airtime balance and `*323#` for data balance instead of memorising a separate code for each operator.

## Why do old USSD codes still appear in Google results?

Many Nigerian tutorials were written before the harmonised codes were implemented, and some newer pages have copied those old lists without checking them.

For example, a current-looking page may still tell an Airtel customer to check data with `*140#` or an MTN customer to check airtime with `*556#`. Those are legacy instructions. Start with the harmonised code for the service you need.

## What to do if a USSD code does not work

If a current code returns an error:

1. Confirm that the SIM has network signal.
2. Make sure you dialled the complete code, including `*` and `#` where required.
3. Retry after a few minutes in case the operator's USSD service is temporarily unavailable.
4. Restart the phone or toggle airplane mode if the line is having general network problems.
5. If the problem continues, call **300** from the affected line and ask the network to check the service.

Do not immediately assume an old code is the solution. A failed USSD session can also be a temporary network problem.
