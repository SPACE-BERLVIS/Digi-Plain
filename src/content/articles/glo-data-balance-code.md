> **Quick answer:** To check your Glo data balance in Nigeria, dial **`*323#`** from your Glo line. Glo's current official data pages list `*323#` as a balance-check method. Depending on your bundle, Glo also provides options through **`*312#`**, the **Glo Café app**, and **hsi.glo.com**.

If you found a guide telling you to use `*127*0#`, `*777#`, or another older Glo code, check when it was written. Many old instructions remain in Google results even though Nigeria's harmonised USSD system has changed the main codes people should use.

## How to check Glo data balance with *323#

The simplest current method is:

1. Open the Phone or Dialer app on the phone using your Glo SIM.
2. Dial **`*323#`**.
3. Press the call button and make sure the request is sent from your Glo SIM if you use a dual-SIM phone.
4. Wait for the balance information on screen or by SMS.

Glo's current revised-data-bundle page specifically lists `*323#` for checking data balance.

## Can I check Glo data balance with *312#?

Yes. Glo's official data-plan FAQ also lists **`*312#`** as a way to access data-balance information for its bundles. `*312#` is primarily the harmonised data-services menu, so it is useful when you want to manage a plan rather than only perform a quick balance check.

For the fastest direct check, start with **`*323#`**.

## Check your Glo data balance with the Glo Café app

Glo also provides its self-service app as an official balance-check method.

1. Open the Glo Café app.
2. Sign in with your Glo number if required.
3. Check the data information shown in your account.

The app can be more useful than USSD when you have several bundles or bonuses and want more detail about your account.

## Check Glo data balance online

Glo's current revised-data-bundle information also directs customers to **[hsi.glo.com](https://hsi.glo.com/)** as an online option for checking data information.

This requires an internet connection, so `*323#` is normally more convenient when you only need to know how much data remains.

## Does *127*0# still check Glo data balance?

You will still find `*127*0#` in many search results because it was a widely used Glo-specific data-balance code.

The problem is that some recently updated third-party pages continue to recommend old Glo codes even while Glo's current official pages now prominently use the harmonised codes. That can make search results confusing.

For a current guide, use **`*323#` first** because that is the data-balance code shown on Glo's live revised-data-bundle page.

Glo's own website also contains older FAQ material that still mentions legacy SMS and shortcode methods for some products. This is another reason it is better to follow the instructions for your current bundle rather than assume every historical Glo code applies to every plan.

## How to check the balance of a Glo special bundle

Some Glo bundles have additional management options.

For example, Glo's current FAQ says hourly data bundles can be checked through `*312#` or `*323#`, while its current YouTube Special page directs customers to `*323#` or the Glo Café app.

If `*323#` shows several balances, pay attention to which balance belongs to your main bundle and which belongs to a bonus or special-purpose bundle.

## What to do if *323# is not working on Glo

Try these checks before assuming the code has changed:

- Make sure the USSD request is being sent from the Glo SIM on a dual-SIM phone.
- Check that your phone currently has Glo network signal.
- Wait a few minutes and try again if the network returns a temporary USSD or MMI error.
- Dial `*312#` and use the data-management menu as an alternative.
- Check through the Glo Café app if you have internet access.
- Visit [hsi.glo.com](https://hsi.glo.com/) for another official self-service option.

If several Glo USSD services fail at the same time, the issue may be temporary rather than a problem with your data bundle.

## Useful Glo data codes to remember

For current Glo data services, these are the most useful starting points:

| What you want to do | Code |
| --- | --- |
| Check data balance | `*323#` |
| Open data-plan/services menu | `*312#` |
| Manage many Glo services | `*301#` |

Glo describes `*301#` as a universal menu for managing services on a Glo line, including data-related actions. For a direct data balance check, however, `*323#` remains the clearer choice.
