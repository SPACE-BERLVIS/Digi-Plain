> **Quick answer:** To check your Airtel airtime balance in Nigeria, dial **`*310#`** from your Airtel line. Airtel Nigeria's current prepaid user guide lists `*310#` as the unified balance-inquiry code, and Airtel says your account balance will be displayed on your phone screen.

If an older article gives you a different Airtel balance code, use `*310#` first. Nigerian mobile networks moved many services to harmonised USSD codes, and Airtel's current support material consistently lists `*310#` for airtime balance checks.

## How to check Airtel airtime balance with USSD

1. Open the Phone or Dialer app on the phone using your Airtel SIM.
2. Dial **`*310#`**.
3. Press the call button.
4. Wait for Airtel to display your current account balance.

Airtel lists the balance inquiry as free on its current service guide.

## How to check Airtel bonus balance

Your normal airtime balance and promotional bonuses are not always the same thing.

Airtel's current FAQ says customers can dial **`*310*1#`** to see a bonus breakdown. Some tariff plans can have their own balance or bonus options, so follow the menu or plan-specific instructions if your bonus is not shown with your main airtime.

For example, Airtel's current SmartTALK page also tells customers to use `*310#` to check airtime and bonus information.

## What is the difference between Airtel airtime balance and data balance?

Use the right code for what you want to check:

| What you want to check | Current Airtel code |
| --- | --- |
| Airtime/account balance | `*310#` |
| Data balance | `*323#` |
| Data plans | `*312#` |
| Recharge | `*311#` |
| Borrow airtime | `*303#` |
| Airtime transfer (Me2U) | `*321#` |

If you want to see your remaining internet data rather than call credit, read our [Airtel data balance code guide](/internet/airtel-data-balance-code/).

If you want to send regular airtime to another Airtel number, see [how to transfer airtime on Airtel](/internet/how-to-transfer-airtime-airtel/).

## Why do some websites show a different Airtel balance code?

Some search results and older tutorials were written before Nigeria's harmonised USSD-code changes or have not been refreshed since the change.

Airtel's current prepaid user guide explicitly lists these unified codes, including `*310#` for balance inquiry, `*311#` for recharge, `*312#` for data plans, `*323#` for data balance and `*321#` for Me2U.

For a code that can change, the network's current support documentation is a safer reference than an undated screenshot or an old social-media post.

## What to do if *310# does not work

If dialing `*310#` gives an error or does not return your balance:

1. Confirm that the Airtel SIM is active and has network signal.
2. If your phone has two SIMs, make sure you send the USSD request through the Airtel SIM.
3. Turn airplane mode on briefly, turn it off, and try again after the line reconnects.
4. Restart the phone if USSD requests are failing generally.
5. Try again later if Airtel's USSD service appears temporarily unavailable.
6. If the problem continues, contact Airtel customer care. Airtel's current prepaid guide lists **300** as its customer-care number.

Do not repeatedly enter random codes from unofficial pages when the official balance code is failing. A temporary network or USSD problem will not normally be fixed by using an obsolete code.

## Can I check Airtel airtime balance without internet?

Yes. `*310#` is a USSD request, so you do not need mobile data or Wi-Fi to use it. Your Airtel SIM does need to be connected to the mobile network for the request to work.
