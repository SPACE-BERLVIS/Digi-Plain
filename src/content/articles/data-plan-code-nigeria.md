> **Quick answer:** Dial **`*312#`** to open the data-plan menu on Nigerian mobile networks. The harmonised code is used for buying and managing data plans. MTN, Airtel and Glo currently publish `*312#` on their official data pages. Choose your preferred bundle from the menu shown on your own network before confirming payment.

If you still remember a different data-subscription code for your network, that is understandable. Nigerian operators used different short codes for years, and old guides are still visible online. The current system uses common short codes for major services, which makes `*312#` the useful code to remember when you want to buy data.

## Data plan code for Nigerian networks

| Network | Data-plan menu |
| --- | --- |
| MTN | `*312#` |
| Airtel | `*312#` |
| Glo | `*312#` |
| 9mobile | `*312#` |

The plans, prices and menu options you see after dialling the code can differ by network and may change over time.

## How to buy data with *312#

1. Put the SIM you want to buy data for in your phone.
2. Dial **`*312#`**.
3. Wait for your network's data menu to appear.
4. Choose the type of plan you want, such as daily, weekly or monthly.
5. Read the data allowance, price and validity before continuing.
6. Choose the payment option offered by your network.
7. Confirm the purchase.
8. Wait for the network's confirmation message before assuming the bundle is active.

Do not copy a direct bundle code from an old article without checking the current menu. Individual bundles and prices change more often than the main `*312#` menu code.

## MTN data plan code

MTN Nigeria's current data-plan page tells customers they can activate data by dialling **`*312#`**. MTN also publishes direct SMS keywords and direct USSD routes for individual bundles, but those depend on the particular plan.

If you are not sure which MTN plan you want, starting with `*312#` is safer than memorising a code for one specific bundle.

## Airtel data plan code

Airtel Nigeria also currently lists **`*312#`** as its data code. Airtel's official data page says customers can dial it to view and subscribe to available plans, or use the My Airtel self-care app.

Airtel currently groups plans into options such as daily/night, weekly, monthly, binge and other offers. What is available to you should be checked in the live menu because offers can change.

After buying a bundle, you can use **`*323#`** to check your remaining data. Our [Airtel data balance guide](/internet/airtel-data-balance-code/) explains the current balance-check method and why older codes may still appear in search results.

## Glo data plan code

Glo's current official pages also use **`*312#`** for data subscriptions. For example, Glo's current Always ON bundle page tells customers to dial `*312#` to subscribe and also publishes direct codes for specific plans.

If your main goal is simply to find a plan, use the main `*312#` menu first. If you already have data and only want to see what remains, read our [Glo data balance code guide](/internet/glo-data-balance-code/).

## What about 9mobile?

The harmonised data-plan short code is **`*312#`**. Dial it from the 9mobile line you want to use and follow the menu displayed on the phone. Because plan availability and operator documentation can change, rely on the live network menu for the exact bundle price and validity rather than an old list of 9mobile bundle codes.

## Is *312# the same as *323#?

No. They serve different purposes.

- **`*312#`** — data plans and subscriptions
- **`*323#`** — data balance enquiry

If you already bought data and only want to know how much remains, `*323#` is the relevant harmonised balance code rather than `*312#`.

## Why do some websites show different data codes?

There are two common reasons.

First, older network-specific codes can remain indexed long after operators change their customer-service routes. Second, networks may still publish direct codes for particular bundles even though `*312#` is the main data-plan menu.

That means a direct code can be valid for one specific offer without replacing `*312#` as the general starting point.

## What to do if *312# is not working

Try these checks before repeatedly dialling the code:

1. Confirm that the correct SIM is selected if your phone has two SIM cards.
2. Check that the phone has a mobile-network signal.
3. Wait a few minutes and try again if USSD requests are temporarily failing.
4. Restart the phone or toggle airplane mode if the SIM appears stuck without service.
5. Use your network's official app or website if USSD remains unavailable.
6. Contact your network's official customer support if other USSD services also fail.

A failed USSD request does not necessarily mean the code has changed. It can also be a temporary network or device problem.

## Should you use a direct data bundle code from Google?

Check it before paying. Data allowances, prices and promotional plans can change. A page may rank in search even when the bundle it describes has already been revised.
